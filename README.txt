NOTEBOOKS

Linkable topic-reference notebooks — dense, shareable notes on
philosophy, mathematics, history, and science. Browsable at
krisyotam.com/notebooks.

Each notebook is a self-contained page on a single topic, written
to be shared when someone asks "what do you know about X?" They
are not blog posts. They are reference material.
